# 🧬 DNA Central Dogma Toolkit

A Python-based bioinformatics toolkit for analyzing DNA sequences and demonstrating the central dogma of molecular biology.

The toolkit allows users to analyze DNA sequences, perform DNA sequence operations, transcribe DNA into mRNA, translate mRNA into a protein sequence, and search DNA sequences for specific motifs.

The project provides both a command-line interface (CLI) and a graphical user interface (GUI).

---

## 📖 Overview

The DNA Central Dogma Toolkit is designed as an introductory bioinformatics application using Python.

The main biological workflow represented by the toolkit is:

DNA → mRNA → Protein

This represents the central dogma of molecular biology:

- DNA is analyzed and validated.
- DNA can be transcribed into mRNA.
- mRNA can be translated into a protein sequence.

In addition to the central dogma workflow, the toolkit provides several DNA sequence analysis and manipulation functions.

## ✨ Features

### 🧬 DNA Analysis

The toolkit can calculate:

- Sequence length
- Number of A bases
- Number of T bases
- Number of G bases
- Number of C bases
- Percentage of each nucleotide
- GC content
- AT content

### 🔄 DNA Operations

The toolkit supports:

- Complement generation
- Reverse complement generation
- Compatibility checking between two DNA strands

### 🧬 Transcription

The program converts a DNA template strand into mRNA using complementary base pairing.

DNA → mRNA

The mapping used is:

| DNA | mRNA |
|-----|------|
| A | U |
| T | A |
| G | C |
| C | G |

### 🧪 Translation

The toolkit translates an mRNA sequence into a protein sequence.

mRNA → Protein

Translation begins at the first AUG start codon and continues in codons of three nucleotides until a stop codon is encountered.

### 🔎 Motif Analysis

The program can search a DNA sequence for a user-specified motif and report:

- Number of occurrences
- Positions where the motif occurs

### ⚠️ Input Validation

The program checks user input and rejects invalid sequences.

DNA may contain only:

A, T, G, C

mRNA may contain only:

A, U, G, C

Invalid input generates an error message and allows the user to try again.
